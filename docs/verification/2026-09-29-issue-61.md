for both fixture types. Protocol version is now declared independently of the
package version and the release audit inspects both distribution formats.

No live product defect has been established yet. SSH key unlocking was an
operator prerequisite before any Forgejo configuration existed, not evidence
of a missing Forgejo Doctor diagnostic.

private temporary Git repositories, and a loopback fake HTTP server. They are
not live release trials. The existing CI layout already places ordinary smoke
in the PR group and duplicate source-export smoke in main/nightly; no actions,
permissions, triggers, dependencies, or configuration fields change here.

Two required follow-up issue bodies are prepared but not yet published:
Forgejo dual-mode live verification and standalone specification consolidation.
Public issue links remain pending. Dual mode remains explicitly unverified
by a real Forgejo loop. Existing #54/#60 API/setup probes do not close the
