## Defects found and fixed

`doctor` now diagnoses missing or wrong forge credentials, inaccessible
repositories, insufficient Reviewer permissions, a missing remote base branch,
stale/missing skills or links, and orphaned resources. The existing Herdr
contract checks and live-probe lifecycle remain in use. Skill checks never
install or overwrite files. Root write probes remove only empty directories
they created; detached-worktree probes use a unique path and ordinary Git
removal, preserving unexpected data or a checkout that cannot be removed.

Reviewer write access comes from the collaborator endpoint's base
`permission`, not its role label. GitHub maps maintain/custom roles to their
base permission; see the official
[collaborator permission endpoint](https://docs.github.com/en/rest/collaborators/collaborators#get-repository-permissions-for-a-user).
Both configured identities are verified using `GET /user` before their
repository checks. Error output never contains a token, including when the
fake forge deliberately echoes its fake credential in an error.

## Scope and limitations

The deterministic suite uses fake GitHub and Herdr processes, temporary Git
repositories, and a temporary HOME populated with packaged role skills and a
scripted code-review skill. It never launches a model or depends on the user's
installed skills. Orphan PR state is read from the forge and cached only within
the current doctor invocation; matching names in another repository are
excluded using Git identity. API failures are reported as failures, never
interpreted as evidence that a PR is closed.

No configuration migration, automatic garbage collection, prompt answering,
README rewrite, version bump, release-wide smoke expansion, or live review
loop is included. Agent Squad's own PR follows the manual review workflow in
§4.4 and the development-session instructions.

The SSH prerequisite failure is resolved. Both repositories have now passed
doctor and their live startup probes. Exact-HEAD CI remains a separate gate
that is verified and recorded in the PR before the manual review handoff.
