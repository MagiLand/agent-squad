## Defects found and fixed

- Collapsing the role accounts exposed an old root-comment check: it imposed the Implementer recovery-copy restriction on the shared login, which is also the Reviewer. Restrict that special check to distinct role accounts; preserve the original dual rule. Unit and fake-forge integration tests now exercise shared findings, dispositions, and verification.
- A newer dismissed or old-head human review must not revive an older approval. Select the latest decision by timestamp instant and ID before testing eligibility. A latest request-changes remains a veto regardless of its head; replacement approval clears it.
- An approved last-budget-slot agent review must wait for human approval without requesting another review. Separate agent-side validity from the human conditions and order the wait before budget exhaustion, while preserving stop, decision, and missing-disposition gates.
- Update both ordinary and source-export smoke expectations for the thirteenth step.

The initial live doctor attempt was blocked by sandbox access to Git metadata, network, credential store, and the Herdr socket. Retrying the same command with normal access cleared those failures. A scratch formatting-tool invocation initially lacked its module import path; it made no source change before failure. Early test-authoring failures were a fake-call-log `None` body assumption and the root-comment defect above; neither is counted as passing validation.
