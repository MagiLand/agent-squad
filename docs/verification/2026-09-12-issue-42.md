## Defects found and fixed

- A fresh clone can lack a replaced review head. Derivation now fetches valid
  historical review targets before checking ancestry, preserving their budget
  contribution. A regression test replaces a remote head and proves that a
  fresh clone still counts the earlier review.
- The initial fake Herdr response used the wrong schema definition name. It
  now models the installed `ResponseResult` contract; deterministic tests cover
  missing capabilities, protocol mismatch, and outdated integration.
- The installed Claude integration was v8 while Herdr required v9. The retained
  doctor correctly failed. `herdr integration install claude` refreshed the
  existing integration after its hook and settings were backed up; doctor then
  passed. The failure was not suppressed or reclassified.

## Scope and limitations

Reviews, findings, decisions, dispositions, verifications, stops, and recovery
faults in the automated smoke are scripted. It covers the forge portion of
§16.3, including the derived human-decision gate, invalidation after a push,
budget extension, batch rejection, missing roots, and explicit resumption.
It does not launch a Reviewer. The human-decision refusal is checked through
derived gates and a blocked thread-resolution attempt; Reviewer launch belongs
to Increment 2.

The live exercise proves real GitHub identity selection, formal review
publication, inline anchors, the forge-state mirror, and state read-back.
It does not prove independent agent judgment, either live harness direction,
Herdr delivery, approval, merging, or the later full live scenarios.

The v0.4.4 baseline, historical development plan, and earlier verification record
remain historical reference material. Active runtime code and user guides use
the new protocol. Changes to the v0.5.0 delta are limited to the alignment list
in issue #42. The package version remains unchanged until Increment 5.

GitHub review and comment mechanics follow the documented
[review endpoints](https://docs.github.com/en/rest/pulls/reviews) and
[review-comment endpoints](https://docs.github.com/en/rest/pulls/comments).
