## Defects found and fixed

No Agent Squad defect was found; nothing was filed or fixed. REV-2 was a
real defect in the trial's own fixture code, found by the review and fixed
inside the trial PR.

Observations, not defects:

- The first Reviewer launch exited 3 at a startup prompt for the new trial
  path (Codex then recorded the checkout as trusted), retained its resources, and `reviewer adopt` delivered the
  request after the Developer answered. This is the designed path for a
  startup prompt (§8). The second launch, under the now-trusted checkout, had
  no prompt.
- The first `reviewer launch` made Herdr create a workspace for the trial
  checkout as well as the Reviewer's workspace. The trial Implementer's pane
  sat inside this repository's workspace, so the trial checkout had no
  workspace of its own. No Agent Squad cleanup owns that workspace; it was
  closed during teardown with the Developer's approval.
- `status` does not report dismissal flags, so they were read from the API.

## Scope and limitations

Real: model agents in both roles, a real Forgejo 16.0.3 server, its branch
protection, Herdr handoffs, and Git. Seeded: only the first revision's
disclosed omission. Nothing was scripted on the forge by the trial loop.

Still unverified after this trial:

- Network transport: the API and Git used plain HTTP on loopback, so HTTPS
  and SSH are not verified for two accounts. #61 trial 4 covers them for the
  identity mode removed in v0.7.0.
- Other Forgejo versions than 16.0.3.
- The other direction, Codex implementing and Claude Code reviewing.
- Squash merge, and an explicit successful branch DELETE: the forge deleted
  the branch during the merge.
- A forge-side merge refusal, and blocking on an undismissed rejected review.
- The CLI's own reading of branch rules (`not visible` to the Implementer).
- Whether review 1 was dismissed at the approval or at the merge.
- Interrupted publication and `--resume`, pending drafts, Task amendments,
  decisions, stops, human reviews, `issue comment` and `issue create`.
- Resolution of a Forgejo thread, which the CLI refuses.
