## Defects found and fixed

- Herdr can return a newly opened workspace before its shell is ready.
  `agent start` then reports `agent_pane_busy`, before starting a process.
  The lifecycle retries only that explicit refusal for at most five seconds,
  rechecking the owned workspace and original terminal between attempts.
  Other startup failures, blocked startup, and prompt failures are not retried.
  The existing 45-second adapter call timeout is unchanged.
- Codex accepted an after-start Herdr prompt without executing or displaying
  the request. Selecting the initial-prompt constant produced the exact skill
  marker. No consumer setting selects delivery behavior.
- A path and head cannot prove that Agent Squad created a checkout. The
  approved ownership record binds the path, full head, common Git directory,
  reserved name, and Herdr workspace/pane/terminal IDs. Tests preserve a
  manually created matching checkout, altered or symlinked metadata, replaced
  occupants, and workspaces with additional tabs or panes.
- Cleanup must not remove an owned checkout merely because it lacks a Herdr
  ownership record while an unowned workspace still uses it. That case now
  retains the checkout and workspace. Lost Herdr worktree registration uses
  the recorded isolated workspace for the specified close-plus-Git fallback.

## Scope and limitations

The automated forge reviews, findings, dispositions, decisions, stops, process
states, and failures are scripted. Fake Herdr starts no model or harness; its
removal operation calls Git only within the disposable fixture repository.
The smoke adds Reviewer launches and closes, refused launches, fixed result
and stop messages, and lost-notification discovery. Merge and the full
Increment 5 scenario remain outside this increment.

The real harness sessions exercised skill delivery, blocked recovery, trust,
and cleanup. Their temporary skill deliberately performed no substantive
review and contacted neither GitHub nor the Implementer. Formal review
judgment, the production skills, skill installation, and `pr merge` belong to
later increments. Agent Squad's own PR continues to use the existing manual
review pipeline.

The Increment 1 baseline had already removed the v0.4.4 dispatch functions and
their tests. This increment extends the remaining installed-Herdr discovery
and inspection adapter; it does not recreate removed v0.4.4 orchestration.
