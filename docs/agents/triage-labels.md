# Triage Labels

The engineering skills use five canonical triage roles.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an implementation agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or intervention |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical role, apply the corresponding GitHub label. Edit this mapping if the repository adopts different label names.
